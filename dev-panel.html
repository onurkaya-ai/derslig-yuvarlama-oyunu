Derslig Oyun Mimarisi

Derslig oyunları, tekrar kullanılabilir bir Core SDK üzerine inşa edilmiş modüler yapıdadır. Her oyun, aynı lobby, turnuva ve SCORM altyapısını paylaşır. Bu sayede yeni bir oyun oluşturmak dakikalar içinde mümkün olur.

Yeni Oyun Oluşturma Adımları
1

İskelet Klasörünü Kopyalayın

games/_game-skeleton/ klasörünü kopyalayıp yeni oyununuzun adıyla yeniden adlandırın. Örn: games/carpma-savasi/

2

SEO Etiketlerini Güncelleyin

index.html içindeki <title>, <meta description> ve og:* etiketlerini oyununuza göre düzenleyin.

3

Oyun Motorunuzu Yazın

app.js dosyasındaki _createQuestion() fonksiyonunu kendi soru mantığınızla değiştirin. Bu fonksiyon { display, label, correct, options } döndürmelidir.

4

Lobby Callback'ini Bağlayın

index.html altındaki onStart callback'inde kendi motorunuzu çağırın: GameEngine.start('dl-game-layer', mod, ayarlar);

5

Test Edin ve Paketleyin

Tarayıcıda açıp test edin. Her şey çalıştığında SCORM sekmesindeki talimatlarla paketleyin.

Soru Üretici Şablonu Zorunlu
app.js
_createQuestion: function() {
    // Soru mantığınızı buraya yazın
    const a = Math.floor(Math.random() * 50) + 1;
    const b = Math.floor(Math.random() * 50) + 1;
    const correct = a * b;

    const options = [correct, correct + 5, correct - 3]
        .sort(() => Math.random() - 0.5);

    return {
        display: `${a} × ${b}`,
        label: 'Çarpımı Bul',
        correct: correct,
        options: options
    };
}
Lobby Ayarları İsteğe Bağlı

Lobby'ye özel ayarlar eklemek için DersligLobby._showSettings() fonksiyonundaki ayar seçeneklerini düzenleyin. Ayarlar { sure, basamakSayisi, yuvarlamaTipi } objesine kaydedilir ve onStart callback'ine aktarılır.

SCORM 1.2 Paketleme Rehberi
ℹ
Derslig oyunları SCORM 1.2 standardını kullanır. Bu standart EBA, Moodle ve çoğu LMS platformu ile uyumludur.
1

Dosyaları Hazırlayın

Oyun klasörünüze tüm gerekli dosyaları (index.html, app.js, stil dosyaları) ve imsmanifest.xml dosyasını yerleştirin.

2

imsmanifest.xml Düzenleyin

identifier, title ve <file> etiketlerini oyununuza göre güncelleyin. Tüm kaynak dosyalarının <resource> altında tanımlı olduğundan emin olun.

3

ZIP Olarak Sıkıştırın

Klasörün içindekileri (klasörün kendisi değil!) seçip .zip dosyası oluşturun. imsmanifest.xml dosyası sıkıştırılmış dosyanın kök dizininde olmalıdır.

4

LMS'e Yükleyin

EBA veya Moodle'da "SCORM Paketi Ekle" seçeneğinden .zip dosyasını yükleyin. Sistem otomatik olarak tanıyacaktır.

⚠
Önemli: SCORM paketi oluştururken, assets/ klasörünün tamamını oyun klasörüne kopyalamayı unutmayın. Bağıl yollar (../../assets/) LMS içinden çalışmaz. Aynı dizine kopyalanmalıdır.
SCORM API Entegrasyonu

derslig-core.js Otomatik Yapıyor

Core SDK, SCORM API'yi otomatik olarak bulur ve iletişim kurar. Sizin ek bir şey yapmanıza gerek yoktur. İşte kullandığı API çağrıları:

Fonksiyon SCORM Çağrısı Açıklama
Derslig.init() LMSInitialize("") SCORM oturumunu başlatır
Derslig.dogruCevap() LMSSetValue("cmi.core.score.raw") Puanı LMS'e gönderir
Derslig.bitir() LMSCommit("") Son durumu onaylar
Derslig.cikis() LMSFinish("") SCORM oturumunu kapatır

Erişilebilirlik (Accessibility) Kuralları

  • ARIA etiketleri: Ana konteyner role="main" ve aria-label taşımalıdır
  • Semantik HTML: <header>, <main>, <nav>, <button> doğru kullanılmalıdır
  • Klavye navigasyonu: Butonlar Tab ile erişilebilir, Enter ile tetiklenebilir olmalıdır
  • Renk kontrastı: Metin ve arka plan arasında minimum 4.5:1 kontrast oranı sağlanmalıdır
  • Dekoratif emojiler: Dekoratif emojilere aria-hidden="true" eklenmelidir

Performans Optimizasyonu

  • Font: Google Fonts'tan sadece kullanılan ağırlıkları yükleyin (display=swap)
  • Sesler: CDN üzerinden yüklenir, başarısızlık halinde local fallback devreye girer
  • DOM: Soru geçişlerinde sadece değişen elementler güncellenir (tam innerHTML yenilenmez)
  • Animasyonlar: Sadece transform ve opacity animate edilir (GPU hızlandırmalı)
